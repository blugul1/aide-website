# AIDE — مکمل ویب سائٹ (سنیماٹک ڈیزائن، تین زبانیں)

لائیو: https://imranaslam.pk — کھولنا: زپ کھول کر `index.html` ڈبل کلک کریں۔ اوپر والے مینیو میں **EN ▾** سے اردو/عربی نسخہ کھلتا ہے (`ur/` اور `ar/` فولڈرز)۔ بنیادی مواد آف لائن بھی کھلتا ہے؛ مکمل فونٹس (Noto Nastaliq وغیرہ) کے لیے انٹرنیٹ درکار ہے۔

## ساخت — 75 صفحات (25 × 3 زبانیں) + 404
- **ہوم** — سنیماٹک ہیرو فلم، پروگرام ایکسپلورر، 60 سیکنڈ سیلف چیک، Path Guide، USWA ایکسپلورر، Mani Writes، کتابوں کی جھلک
- **About** — عمران کی کہانی · اعداد · کام کا طریقہ · **ٹیم (عرفان اسلم، عمران اسلم، ظل ہما اسلم)** · **آزاد اقدامات (حلیمہ سعدیہ/ADK، سیدہ عمارہ زیدی/اصلاح نیٹ ورک)**
- **Programmes** — چھ پروگرامز کی فہرست؛ ہر نام اپنے تفصیلی صفحے سے جڑا ہوا
- **ہر پروگرام کا الگ صفحہ** — ماڈیولز (نصاب)، حاصلات، فارمیٹ، فیس، کس کے لیے، وٹس ایپ بٹن: `programme-pldp / -habits / -sales / -teach / -homes / -rise`
- **Books** — 55 کتابوں کی دکان (اردو فہرست: کارٹ، 8 بنڈل، تحفہ نظام، نمونے؛ انگریزی/عربی جائزہ + پہلی 4 کتابوں کی تفصیل)
- **Assessments** — 25 سیلف چیک (8 دستخطی آئینوں سمیت)، مقامی معاون، ذاتی ڈیش بورڈ — کوئی کلینکل اسکریننگ نہیں
- **Resources · Coaching · Mani Writes · Contact · Start** + **4 پالیسی صفحات** (واپسی، ترسیل، شرائط، رازداری) + **5 پروفائل صفحات**
- **مینیو:** About اور Programmes اور Coaching کے ڈراپ ڈاؤن + Resources ڈراپ ڈاؤن + زبان سوئچر؛ موبائل مینیو میں گروپس

## طریقہ کار — کم ٹوکن میں تبدیلی
سائٹ `src/` میں چھوٹے حصوں میں ہے۔ بنانے کی ترتیب (یہی ترتیب لازمی):
1. `python3 src/books_gen/build_books.py` — اردو کتابوں کا صفحہ (JSON + محفوظ اصل سے)
2. `python3 src/build.py` — باقی 24 صفحات × 3 زبانیں
3. `python3 src/home_gen/build_home.py` — تینوں ہوم صفحات

| فائل | ذمہ داری |
|---|---|
| `src/css.css`, `pages.css`, `pages2.css` | تمام ڈیزائن + ڈراپ ڈاؤن + RTL قوانین |
| `src/nav.html` / `ur/nav.html` / `ar/nav.html` | مینیو (ڈراپ ڈاؤن سمیت) |
| `src/footer.html` (+ ur/ar نسخے) | اختتامی CTA + فوٹر |
| `src/js.js` | مشترکہ جاوا اسکرپٹ: کارٹ، تاریخ کے لحاظ سے قیمتیں (PKT)، ریڈر، کوئز |
| `src/ac-app.js` | اسسمنٹ سینٹر: 25 ٹیسٹ، معاون، ڈیش بورڈ |
| `src/books_gen/` | اردو فہرست کا جنریٹر + محفوظ اصل (`ur-books-orig.html`) — تفصیل و نمونے یہیں سے محفوظ رہتے ہیں |
| `src/home_gen/` | ہوم صفحات: مواد `loc_*.py` میں |
| `src/progdata.py`, `pldp_page.py`, `profiles.py` | پروگرامز/پروفائلز کا تصدیق شدہ ڈیٹا (3 زبانیں) |
| `src/*.html` (+ ur/ar) | ہر صفحے کا اپنا مواد |

تبدیلی کا خرچ تبدیلی جتنا: متن بدلنا ہو تو صرف وہی چھوٹی فائل؛ پروگرام کی تفصیل بدلنی ہو تو `progdata.py` کی ایک انٹری۔ بنے ہوئے صفحات میں براہ راست تبدیلی ممنوع — ہمیشہ `src/` بدلیں، پھر بلڈ کریں۔
