# آزمائشی اسیسمنٹ ایپ — README

تین اصل اردو اسیسمنٹ کا آزمائشی پول چلانے کے لیے چھوٹی سی ایپ۔ کوئی سرور نہیں،
کوئی ڈیٹا کہیں نہیں جاتا۔ جوابات صرف جواب دینے والے کے اپنے آلے پر محفوظ ہوتے ہیں۔

## فائلیں

- `items.json` — تینوں اسیسمنٹ کے آخری سوالات (93 سوال: پہلی 28، دوسری 35، تیسری 30)۔
  ایپ سوالات اسی فائل سے لیتی ہے۔ پول کا نسخہ (130 سوال) `items-pool.json` میں محفوظ ہے۔
- `index.html` — اسیسمنٹ چلانے والا صفحہ (اردو، دائیں سے بائیں)۔
- `app.js` — صفحے کی منطق: اسکورنگ، نتائج، فائل اتارنا۔
- `analysis.py` — اتاری گئی CSV فائلوں کا تجزیہ (الفا، ارتباط، جھنڈے)۔

## آزمائش کیسے چلائیں

1. یہ فولڈر کسی بھی کمپیوٹر پر رکھیں اور اس میں یہ حکم چلائیں:

   ```
   python3 -m http.server 8000
   ```

   پھر براؤزر میں `http://localhost:8000/` کھولیں۔
   (براہ راست ڈبل کلک سے کھولنے پر براؤزر `items.json` نہیں کھولتا، اس لیے
   اوپر والا طریقہ استعمال کریں۔ یا یہ فولڈر کسی بھی سادہ ویب ہوسٹنگ، مثلاً
   GitHub Pages، پر ڈال دیں۔)

2. جواب دینے والا ایک اسیسمنٹ چنتا ہے، اختیاری معلومات دیتا ہے (عمر، جنس، شہر)،
   اور 28، 35 یا 30 سوالوں کے جواب دیتا ہے۔ ہر سوال کے چار جواب ہیں:

   کبھی نہیں = 0 | کبھی کبھار = 1 | اکثر = 2 | تقریباً ہمیشہ = 3

   الٹے سوال میں نمبر الٹا ہو جاتا ہے (3 کا مطلب 0)۔

3. نتیجے کے صفحے پر ہر پیمانے کا مجموعہ اور کل نمبر دکھائی دیتا ہے۔ ابھی کوئی
   درجہ بندی یا نتیجہ طے نہیں ہوا، نمبر صرف آزمائش کے اعداد ہیں۔

4. جواب دینے والا اپنے جوابات JSON یا CSV فائل کی صورت میں اتار کر آزمائش کے
   منتظم کو بھیج دیتا ہے۔ فائل میں نام نہیں ہوتا، صرف ایک خفیہ کوڈ ہوتا ہے۔

5. ایک ہی آلے پر کئی لوگ جواب دے سکتے ہیں۔ "اس آلے کے تمام جوابات" والا بٹن
   سب کو ایک فائل میں اتار دیتا ہے۔

## نمونہ کتنا ہو

- **چھوٹی آزمائش:** 30 سے 60 جواب دہندگان۔ اس سے یہ پتہ چلتا ہے کہ سوالات
  سمجھ میں آتے ہیں یا نہیں، اور کون سا سوال کمزور ہے۔
- **بڑی توثیق:** 200 سے 500 جواب دہندگان۔ اس سے پیمانے کی اصل مضبوطی،
  ساخت اور نمبروں کے درجے طے ہوتے ہیں۔

30 سے کم جواب پر الفا صرف اشارہ ہوتا ہے، فیصلہ نہیں۔

## تجزیہ کیسے کریں

تمام اتاری گئی CSV فائلیں ایک فولڈر میں رکھیں اور چلائیں:

```
python3 analysis.py /path/to/csv-folder/
```

ہر پیمانے کے لیے یہ نکلے گا:

- **کرونباخ الفا** — پیمانے کی اندرونی مضبوطی۔ 0.70 قابل قبول، 0.80 اچھا،
  0.90 بہترین مانا جاتا ہے۔
- **درست شدہ آئٹم-کل ارتباط** — ہر سوال کا اپنے پیمانے کے باقی سوالوں سے تعلق۔
- **الفا اگر آئٹم ہٹایا جائے** — یہ سوال ہٹانے سے پیمانہ بہتر ہوتا ہے یا نہیں۔

**جھنڈا** ان سوالوں پر لگتا ہے جن کا ارتباط 0.30 سے کم ہو، یا جن کے ہٹنے سے
الفا بڑھ جائے، یا جن میں کوئی تغیر ہی نہ ہو (سب نے ایک جیسا جواب دیا)۔
جھنڈا کھانے والا سوال خود بخود خارج نہیں ہوتا؛ ماہرین اسے دیکھ کر فیصلہ کرتے ہیں۔

رپورٹ JSON میں بھی محفوظ کی جا سکتی ہے:

```
python3 analysis.py /path/to/csv-folder/ --json report.json
```

## اہم باتیں

- یہ آزمائش سے پہلے کا آخری نسخہ ہے، آزمائشی پول نہیں۔ آخری 28، 35 اور 30 سوالوں کا انتخاب
  ماہرین کے جائزے کے بعد طے ہو چکا ہے؛ درجے اور بینڈ آزمائش کے بعد بنیں گے۔
- ایپ کوئی ڈیٹا سرور پر نہیں بھیجتی۔ جوابات صرف اتاری گئی فائلوں کے ذریعے
  منتظم تک پہنچتے ہیں۔
- `analysis.py` کوئی فرضی ڈیٹا نہیں بناتا۔ اگر کوئی CSV نہ ہو تو وہ کچھ نہیں کرتا۔
